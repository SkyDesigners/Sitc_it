# SITC Diploma in Information Technology Landing Page

React + Vite landing page designed to closely follow the supplied reference screenshot while using course details and visuals from the supplied **Diploma in Information Technology - September Intake 2026** PDF.

## Run locally

```bash
npm install
npm run dev
```

## Build for deployment

```bash
npm run build
```

Upload the generated `dist/` folder to your web hosting or deploy the repository to Vercel/Netlify.

## Main files

- `src/App.jsx` - page content and interactive accordions/countdown
- `src/styles.css` - full responsive layout and screenshot-matched visual theme
- `public/assets/` - SITC / programme visuals extracted from the supplied PDF

## Important

Payment, schedule and contact details are based on the supplied course PDF. Verify current intake/payment availability before publishing or accepting payments.
